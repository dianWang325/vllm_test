# GLM-5.2 cross-node PP2 experiment (2026-09-16)

Model: `/mnt/weight/GLM-5.2-W4A8C8-0713-MTP`. Both nodes run the
`wd_test0825` container with 16 logical NPU devices each. The deployment uses
TP=16, PP=2, expert parallelism, AIV HCCL expansion, and an 85 Ki-token
context (`--max-model-len 87040`). PP0 serves the OpenAI API on
`127.0.0.1:18080`; PP1 is headless.

## Launch scripts

- `plain_scripts/test_pp2_glm52_ep_135_127_VERIFIED_40k.sh`: original
  successful 40 Ki-token run on 80.5.9.135 (PP0) and 80.5.9.127 (PP1).
- `plain_scripts/test_pp2_glm52_ep_135_127_85k.sh`: verified 85 Ki-token run
  on the same pair, including a successful chat completion and the two
  prefill workloads below.
- `plain_scripts/test_pp2_glm52_ep_126_127_85k.sh`: replacement pair with
  80.5.9.126 as PP0 and 80.5.9.127 as PP1. Both stages loaded and passed
  memory profiling; `/v1/models` reported `max_model_len=87040`, and a chat
  completion succeeded. The service was stopped when 126 was reserved.
- `plain_scripts/test_pp2_glm52_ep_113_127_85k.sh`: subsequent replacement
  with 80.5.9.113 as PP0 and 80.5.9.127 as PP1. Startup and both prefill
  workloads succeeded; both service processes were stopped immediately after
  the workloads completed. Neither container was stopped.

Pass `head` on PP0 and `worker` on PP1. Start both roles against the same
